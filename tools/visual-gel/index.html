Visual GEL editor

Open a project GEL file and choose a function. Edit statements and control-flow headers as blocks, or add blocks inside existing bodies. Comments, assembly and unsupported source are preserved read-only.

This is an incremental editor, not full GEL coverage. Syntax is checked before saving; the game build is still needed to check symbols and types. Changes to generated contact.gel belong in the contact editor.

Declarations & memory

Declarations are currently read-only here. Memory addresses come from the latest compiler output, not the live game; rebuild after changes. A failed build can leave this output out of date.

Compiled memory sizes

Reported low WRAM occupancy

Compiler-reported allocations in the 8 KiB low WRAM window ($0000–$1FFF). Unreported space is not necessarily free: stack, scratch space, function frames and other reservations are not shown in the compiler summary. MMIO is not RAM. This overview is independent of the filters and selections below.

Bars compare reported sizes with the largest visible item. Select items to total their sizes; MMIO is shown separately from RAM. Table fields can be interleaved, so a field's bytes may not be contiguous. Function frames and other unreported allocations are not included.

Clipboard

Tick statements and choose Copy or Cut. Each copy is kept here as its own entry, also across functions and files. Paste goes before the single ticked statement, or to the end of the function if none is ticked.
