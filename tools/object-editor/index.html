Define capabilities for Tiled object classes. Names match classes case-insensitively; numeric IDs are assigned by the level build.

These flags are initialized on spawned entities, but the general flag-driven physics, input and contact systems are not implemented yet. Existing game behavior is unchanged.

Variants are assigned an ID automatically. Set the Tiled object's param byte to that ID. Entity field overrides apply at spawn; custom values are read by shared GEL behavior. Rendering is not changed.

Movable means the object can receive movement intent from a controller or behavior; it does not automatically receive player input. Forces may also move it.
