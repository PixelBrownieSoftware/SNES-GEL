ROM overview

ROM size

The ROM size is a minimum. The build always grows the ROM to the next power of two that fits the code, assets, sound and level data, so you can enlarge it but not shrink it below what the game needs.

Asset start is where graphics begin in the first bank. Code runs from $8000 up to it, so raising it gives the code more room, and lowering it gives graphics more room. It is a multiple of 256, written like $C000.

Saved changes take effect on the next build.
